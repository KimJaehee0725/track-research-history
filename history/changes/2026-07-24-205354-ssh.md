# Change - 프로필 기반 메모리 접근과 SSH 키 관리 단순화

Date: 2026-07-24 20:53 +0900
Agent: codex
Status: completed

## Why

매 호출마다 연결 정보와 프로젝트 ID를 반복하고 authorized_keys를 수동으로 조립해야 해 일상 사용과 키 교체가 복잡했다.

## How

로컬 비밀 없는 프로필과 기본 프로젝트 생략, profile-aware memory-run, 서버 측 marker 기반 SSH 키 grant/list/revoke 도구를 추가했다. 컨테이너에는 프로필의 `known_hosts`와 SSH config도 선택 키와 함께 read-only mount해 host 검증을 유지한다. Compose UI는 그대로 유지하고 systemd 단일화는 별도 점검 전환으로 문서화했다.

## Risks / Follow-Ups

실서버 Compose 서비스와 authorized_keys는 이 변경으로 수정하지 않았다. 새 키 관리 도구는 서버에 새 코드를 배포한 뒤 sudo로 실행해야 한다.

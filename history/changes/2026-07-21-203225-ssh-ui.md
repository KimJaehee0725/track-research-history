# Change - SSH 중앙 메모리 서버와 관리 UI 추가

Date: 2026-07-21 20:32 +0900
Agent: codex
Status: completed

## Why

연구실 서버와 노트북의 새 컨테이너가 프로젝트별 메모리를 지속적으로 공유하고, 사람이 안전하게 삭제·복구할 수 있게 한다.

## How

프로젝트 격리 Markdown 저장소, SQLite FTS5/revision/trash/audit, SSH JSON RPC, loopback FastAPI UI, Docker/systemd 배포 예시, 컨테이너 키 주입 래퍼와 Obsidian 운영 문서를 추가했다.

## Files

- src/research_memory/store.py
- src/research_memory/rpc.py
- server/app.py
- server/rpc.py
- client/memctl.py
- client/memory-run
- deploy/docker-compose.yml
- docs/server-setup.md

## Validation

- python3 -m unittest tests.collab_behavior_smoke tests.test_memory_store -v
- docker compose -f deploy/docker-compose.yml config --quiet
- FastAPI TestClient CRUD/trash smoke in an isolated temporary virtual environment

## Risks / Follow-Ups

실제 서버에는 서비스 계정 UID/GID, SSH host key, forced-command public keys, private backup target을 운영자가 설정해야 한다. UI를 공용 인터페이스에 노출하면 안 된다.

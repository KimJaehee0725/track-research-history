# Change - 개인 비밀번호 전체 프로젝트 Research Memory 모드 추가

Date: 2026-07-27 13:26 +0900
Agent: codex
Status: completed

## Why

개인 사용자가 프로젝트별 SSH 키와 profile 설정 없이 하나의 비밀번호로 모든 프로젝트를 선택해 조회·수정할 수 있어야 한다.

## How

MEMORY_PASSWORD 환경변수 기반 sshpass transport, allow-all forced-command SSH fragment, 대화형 서버 전환 도우미, 선택적 MEMORY_PROJECT 흐름을 추가했다. 비밀번호 모드는 사용자 요청에 따라 host-key 검증을 끈다.

## Files

- client/memctl.py
- deploy/ssh/sshd_config.d/research-memory.conf
- deploy/enable-personal-password-mode.sh
- docs/password-mode.md
- examples/memory-password.env.example
- tests/test_client_profiles.py
- tests/test_password_mode_contract.py

## Validation

- python3 -m unittest discover -s tests; python3 -m py_compile client/memctl.py client/profiles.py server/rpc.py; bash -n deploy/enable-personal-password-mode.sh

## Risks / Follow-Ups

비밀번호는 Docker runtime 환경에 존재하고 host-key 검증도 꺼진다. 이 모드는 개인 단일 사용자 서버 전용이며, 서버에서 password mode helper를 실행하고 memory-rpc 비밀번호를 대화형으로 설정해야 실제 접속이 가능하다.

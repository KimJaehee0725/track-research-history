# Decision 0002 - 개인 SSH 메모리 서버를 실시간 원본으로 채택

Date: 2026-07-21 20:32 +0900
Status: superseded

## Context

새 컨테이너와 여러 장비가 같은 프로젝트 메모리를 즉시 읽고 써야 하며, 기존 Git hub 복사본만으로는 동시성·최신성 요구를 만족하기 어렵다.

## Decision

프로젝트별 Markdown Vault, revision, FTS5 인덱스, 감사 로그, 휴지통은 개인 Linux 서버에 둔다. private Git hub는 백업·이력 복제 역할로 유지한다.

## Rationale

SSH forced command로 프로젝트·권한 범위를 고정하고, UI는 localhost와 SSH 터널로 제한하면 공개 웹 포트 없이 다중 컨테이너 접근과 복구 가능한 삭제를 함께 제공할 수 있다.

## Consequences

클라이언트는 memctl SSH RPC를 사용하고, Obsidian은 같은 Vault의 viewer/editor로만 사용한다. 키·실제 데이터·백업 자격 증명은 코드 저장소에 넣지 않는다.
